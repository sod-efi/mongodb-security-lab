# mongodb-security-lab

Authorized, self-contained lab for assessing MongoDB node misconfigurations and
demonstrating lateral movement across a small cluster, then fixing what it finds.

**Lab use only.** See [docs/README.md](docs/README.md) to run it,
[docs/METHODOLOGY.md](docs/METHODOLOGY.md) for the attack chain, and
[docs/REPORT.md](docs/REPORT.md) for an example findings write-up.

```bash
npm install && npm run demo
```
